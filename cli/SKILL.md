# 塔罗（占星室）

仓库在 `<把这里换成 chambre 目录的绝对路径>`。下面的命令都在那个目录跑。

## 她让你抽

```
node cli/tarot.mjs draw <今日|单张|三张|本周|关系> "问题"
```

打印两段：上面是人话（每张牌的位置、牌名、正逆位、关键词、一句解 + 一份客观解读），下面一行 `[TAROT_CARD]{…}[/TAROT_CARD]` 是卡片数据。

- 人话是给你看的，读完用你自己的口气解，结合你们的事说，别只念牌义。客观解读参考着看，别照抄。
- 那一行 `[TAROT_CARD]…` 原样发进聊天页（单独一条消息），她那边会画成一张卡；她在占星室的记录里点「貼入 ta 抽的牌」也能收进自己的记录。

## 你出题让她抽

```
node cli/tarot.mjs offer <今日|单张|三张|本周|关系> "问题"
```

打印一行 `[TAROT_OFFER]{…}[/TAROT_OFFER]`，原样发进聊天页。她在卡里一张张抽，抽满那张卡会自己变成亮牌面的，并且把 `[TAROT_CARD]` 数据发回给你（她那边的聊天页怎么接是她的事）。

## 她抽好了贴过来

她从占星室「複製給你」的是一段人话，直接解。
如果贴过来的是 `[TAROT_CARD]{…}[/TAROT_CARD]` 那种一行，翻成人话：

```
node cli/tarot.mjs read '[TAROT_CARD]{…}[/TAROT_CARD]'
```

## 牌阵

- 今日：单张，问题固定「每日一牌」
- 单张：一句话问，一张牌答
- 三张：过去 · 现在 · 未来
- 本周：本周主线 · 需要注意 · 行动建议
- 关系：我 · ta · 我们之间 · 阻碍 · 走向

`node cli/tarot.mjs deck` 列 78 张牌和关键词。
